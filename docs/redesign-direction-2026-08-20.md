# Dirección de renovación de Edu AI

## Objetivo de producto

Edu AI debe sentirse como un estudio sereno para transformar texto en voz, no como un panel técnico ni un directorio de funciones. La voz es la acción principal; el chat, la biblioteca y las guías acompañan una ruta de creación y aprendizaje.

## Decisiones de experiencia

| Decisión | Aplicación |
| --- | --- |
| Prioridad visible | El estudio de texto a voz conserva el primer lugar y expone información útil antes de generar. |
| Ayuda sin ruido | Se añaden métricas de palabras y duración estimada, además de una acción que ordena espacios y puntuación sin reescribir el texto. |
| Tono humano | Se mantienen los colores cálidos, la tipografía editorial y mensajes concretos en vez de promesas grandilocuentes. |
| Confianza | La cuota, el procesamiento y la protección se explican junto al flujo, sin bloquear la creación con lenguaje técnico. |
| Móvil primero | Las métricas y controles pasan a una sola columna en pantallas estrechas, con objetivos táctiles claros. |

## Límites conscientes

La preparación de narración no altera las ideas ni resume el contenido: solo limpia espacios, conserva saltos de línea y agrega una puntuación final cuando falta. No se añade registro obligatorio ni se activa monetización.
